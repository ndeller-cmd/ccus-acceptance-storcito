# Raw survey data (not public)

This folder is empty in the public package. The raw survey data (SPSS files provided by Norstat) contain personal information and cannot be shared for data protection reasons.

`01_cleaning.R` expects the files here, one per country:

- `survey_DE.sav`
- `survey_NO.sav`
- `survey_NL.sav`

To run the analyses without the raw data, use the synthetic dataset `data/analysis_data_synthetic.rds` (see the main README).
